# Satisfactory Dedicated Server on Eyevinn Open Source Cloud

This project has been containerized and adapted for the [Eyevinn Open Source
Cloud (OSC)](https://www.osaas.io) service catalog.

## What is Eyevinn Open Source Cloud?

Eyevinn Open Source Cloud (OSC) is an open innovation platform that lets you
deploy and run best-of-breed open source projects as managed cloud services —
with one click, no infrastructure to manage yourself. OSC bridges the gap
between promising open source projects and production-ready cloud services,
making it easy for anyone to spin up the tools they need.

If you maintain an open source project, OSC also gives you a path to reach
new users and get support for your continued work — Eyevinn shares revenue
generated by usage of your project back to you as a creator.

## About this service

This is the [wolveix/satisfactory-server](https://github.com/wolveix/satisfactory-server)
dedicated game server for Satisfactory, packaged for deployment on OSC. It
downloads and runs the official, anonymously-licensed Linux dedicated server
binary via SteamCMD.

## Deploying on OSC

Once submitted and accepted into the OSC catalog, this service can be
deployed directly from [osaas.io](https://www.osaas.io) with a single click,
with persistent storage for your save games and game files automatically
provisioned.
